발소리
- 로컬: 실제 CharacterController.velocity + 프레임 간 수평 변위 + Grounded를 확인합니다.
- Idle, 벽에 막힘, 공중, 사망, 관전, CharacterVisual 비활성, 순간이동은 걸음을 만들지 않습니다.
- 특정 클립 이름/애니메이션 이벤트에 의존하지 않으므로 High 전용 걷기에서도 유지됩니다.
- 기존 Starter Assets Player_Footstep_01~05.wav를 재사용합니다. 이전 클립 연속 선택을 피합니다.
- 재사용 AudioSource.PlayOneShot, pitch 0.95~1.05, 음량 변동 ±5%.
- Walk: 간격 0.48초 / 음량 0.40
- Sprint: 간격 0.32초 / 음량 0.55
- Crouch: 간격 0.68초 / 음량 0.18
- 최소 수평 속도 0.15 m/s, Spatial Blend 1, Linear Rolloff, Min 1m / Max 14m, Doppler 0.
- 위 수치는 Inspector에서 조정하는 테스트 기본값입니다.
- 일관된 기존 표면 구분 API가 없어 기본 세트 하나만 사용합니다. 표면 시스템을 추가하지 않았습니다.

호흡
- Idle/Walk/Low/Mid + 달리기 피로 없음: Volume 0 + Stop.
- 실제 지상 Sprint를 3초 이상 지속하면 피로 호흡이 시작됩니다.
- 달리기를 멈추면 4초 동안 회복하며, 0.6초 강도 전환을 거쳐 Volume 0 + Stop이 됩니다.
- HighThreshold 이상: 스트레스 정도에 따라 강도/속도를 높입니다.
- 피로 강도와 스트레스 강도 중 큰 값 하나만 사용합니다. 호흡 Loop는 하나입니다.
- 시작/종료는 Fade In/Out. 사망/관전/비활성화에서는 즉시 정지합니다.

심박
- Heartbeat Start Threshold=-1은 기존 PlayerStressController.HighThreshold를 따릅니다.
- 양수로 지정해도 HighThreshold보다 낮은 단계에서 시작하지 않습니다.
- 짧은 0.45초 단발음을 65~115 BPM, 음량 0.12~0.30으로 반복합니다.
- pitch는 1을 유지합니다. 임계값 아래/사망/관전에서는 즉시 Stop.
- 기존 긴 클립을 유지하는 프리팹에서는 클립 길이만큼 간격을 확보하여 중첩을 막습니다.
