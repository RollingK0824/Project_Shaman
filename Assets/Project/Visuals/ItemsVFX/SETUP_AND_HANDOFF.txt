재생 / 판정 경계
- BellItem/GongItem.OnUseStarted: 요청 가능한 사용의 로컬 연출.
- BellUseAction/GongUseAction.PlayRemotePresentation: 원격 연출.
- BeanMugwortProjectile.InitializeVisual: 표시용 투사체만 궤적 생성.
- BeanMugwortProjectile.Hit: 표시용 투사체의 첫 물리 접촉에만 가루 생성.
  접촉 가루는 귀신 Slow 성공 표시가 아님. 판정용 투사체에는 VFX를 붙이지 않음.
- BarrierWardVisual.ApplyReplicatedState: 처음 활성화됐을 때 1회.
- HouseBarrierWard.Arm: 첫 활성화 때 1회.
- PlayerItemFeedback -> PlayerTalismanCollection.UseCommitted: 효과부적 적용 성공 후 1회.
- VFX에서는 피해/CC/소모/ReportUse를 실행하지 않음.
- 일시 효과 자동 제거, 동시에 최대 32개. 투사체 궤적은 투사체와 함께 제거됨.
- 징 충격파 동안 활성 Base Game 카메라에 색상/깊이 텍스처를 임시 요청하고 원래 값으로 복원.
  방울은 이 카메라 설정을 사용하지 않음.
  프로젝트 URP 설정이나 카메라 프리팹을 저장하지 않음.

네트워크 담당 전달
1. 기존 NetPlayerItemUse.RpcPlayUsePresentation(includeOwner=false)가 호출하는
   UseAction.PlayRemotePresentation에 방울/징/팥쑥 효과가 연결됨.
   소유 클라이언트는 로컬에서 이미 재생하므로 중복 RPC 재생 금지.
2. NetPlayerBarrier의 기존 BarrierWardVisual.ApplyReplicatedState 경로는
   활성 전환 때 새 결계 발동 효과도 재생함. 실제 여러 PC에서의 동시 표시는 추가 확인 필요.
3. 효과부적은 NetPlayerTalisman.CmdUse의 TryUse 성공 시점에 서버 성공 알림을
   해당 플레이어의 관찰자에게 보내는 연결이 필요함.
   수신 측은 ItemVfxPresentation.Talisman(playerGameObject)를 사용 1회당 한 번 호출.
   호스트에서 기존 UseCommitted로 이미 재생된 인스턴스는 RPC에서 중복 재생하지 말 것.
   거절된 요청, 초기 상태 복제, 단순 버프 만료/스냅샷 갱신에서 재생하면 안 됨.
   현 TargetEffects는 상태 동기화이므로 사용 성공 이벤트로 간주하면 안 됨.
4. Network/Ghost/Core 및 팀원 씬은 이번 작업에서 수정하지 않음.
